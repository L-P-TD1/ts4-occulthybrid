# ts4-occulthybrid

This repository contains the script and package code for the OccultHybrid mod, including the adapted version of the Hybrid mod (known as IC_Hybrid).

## Compiling

Assuming that you are using the Sims 4 Modding Workspace template, use the files in the [gist](https://gist.github.com/LordPercivalXII/0994a85158bdb2f8e66dae3e2436ceea), as the Compile file has dependenicies for MultiLibCompiler.

For mod packages, use S4S to edit accordingly.
